# Phase 2B — AutoGluon Top-Three-Features Run

This phase uses the top three features from the completed all-features
AutoGluon experiment and repeats the AutoML search under the same runtime
budget.

## Prerequisite

The following file must exist:

```text
reports/autogluon/all_features/top5_features.csv
```

It is generated by:

```bash
python scripts/run_autogluon_all_features.py
```

## Install the package

Extract this ZIP into the repository root and allow folders to merge.

```bash
source .venv/bin/activate
python -m pip install -r requirements-automl.txt
python -m pip install -e .
```

## Validate

```bash
ruff format src scripts tests
ruff check src scripts tests --fix
python -m pytest -v
```

## Run the experiment

```bash
python scripts/run_autogluon_top_features.py
```

Expected final line:

```text
PHASE 2B AUTOGLUON STATUS: PASS
```

## Generated evidence

```text
reports/autogluon/top_features/
├── selected_top3_features.json
├── autogluon_raw_leaderboard.csv
├── leaderboard_by_validation_score.csv
├── top3_models_by_validation_score.csv
├── leaderboard_by_training_speed.csv
├── top3_models_by_training_speed.csv
├── best_model_metrics.json
├── best_model_test_predictions.csv
├── feature_importance.csv
└── predictor_info.json
```

The direct all-features versus top-features comparison is saved at:

```text
reports/comparison/autogluon_all_vs_top_features.csv
```

## MLflow

Start the UI in a second terminal:

```bash
source .venv/bin/activate
python scripts/start_mlflow.py
```

Open:

```text
http://127.0.0.1:5000
```

Both AutoGluon runs will appear in the same experiment:

```text
athletes-autogluon
```

## Commit

Do not commit `models/`, `mlruns/`, or `mlflow.db`.

```bash
git add \
  configs/autogluon_top_features.yaml \
  src/athlete_automl/autogluon/top_features.py \
  scripts/run_autogluon_top_features.py \
  tests/test_autogluon_top_features.py \
  docs/phase_2b_autogluon_top_features.md

git commit -m "feat: Add AutoGluon top-features experiment"
git push origin master
```

After the run, commit the generated CSV and JSON reports separately:

```bash
git add \
  reports/autogluon/top_features \
  reports/comparison/autogluon_all_vs_top_features.csv

git commit -m "docs: Add AutoGluon top-features results"
git push origin master
```
